# RTMSF manuscript

Author: **Ankit Joshi**.

[manuscript.md](manuscript.md) is the editable paper;
[manuscript.pdf](manuscript.pdf) is its readable A4 export, including all five
measured figures. This is a prepared arXiv manuscript, not a published submission.

The [evidence README](../evidence/paper/README.md) maps each figure/table to its
inputs, source version and limitations. The [experiment specification](../docs/experiments.md)
defines the collection protocol; the [AWS runbook](../docs/aws.md) gives rerun commands.

The PDF uses native macOS typesetting of the Markdown text, tables and original
figure PNGs. Formatting is separate from result generation. The plotted PDFs
remain available for subsequent journal/conference typesetting.

The prepared local source/audit bundle is `dist/rtmsf-0.2.0-paper.tar.gz`.
Its `RELEASE.md` explains checksums and historical-source reproduction. Generated
archives stay outside Git; publishing the repository/archive is a separate action.
